# Confidentialité

## En résumé

- Aucun compte à créer, aucun cookie, aucune publicité, aucune statistique de fréquentation.
- L'application n'envoie aucune donnée au cabinet ni à un serveur.
- Les seules informations que vous pouvez saisir (date de votre dernière consultation) restent dans votre téléphone, et seulement si vous le demandez.

## Date de votre dernière consultation (facultatif)

- La saisie est facultative : vous pouvez ignorer ce bloc.
- Le calcul de la date de votre prochain bilan se fait entièrement dans votre téléphone. Rien n'est transmis.
- La date n'est enregistrée dans votre téléphone (stockage local du navigateur) que si vous cochez « Garder cette date sur mon téléphone ». Sinon, elle est oubliée à la fermeture de l'application.
- Si vous avez gardé la date, l'application refait le calcul à chaque ouverture et affiche, le moment venu, un message vous proposant de refaire un bilan. Ce message n'apparaît que dans l'application ouverte : aucune notification ne vous est envoyée.
- Vous pouvez l'effacer à tout moment avec le bouton « Effacer », ou en effaçant les données du site dans votre navigateur.
- Le rappel est un fichier agenda (.ics) créé dans votre téléphone. Une fois ajouté à votre agenda, il dépend de votre application d'agenda (et, le cas échéant, de son service de synchronisation, comme iCloud ou Google Agenda).

## Ce qui est enregistré automatiquement sur votre téléphone

Pour fonctionner sans connexion, l'application garde sur votre téléphone une copie de ses propres pages (textes, images). Cette copie ne contient aucune information sur vous. Elle disparaît quand vous désinstallez l'application ou effacez les données du site.

## Services tiers

L'application ne charge aucun service tiers tant que vous ne le demandez pas. Ces services ne s'ouvrent que lorsque vous touchez le bouton correspondant :

- **Prendre rendez-vous** ouvre la page de rendez-vous du site du cabinet (osteo-savasta.fr, hébergé par Squarespace), qui intègre le module de réservation Doctolib. Ces services ont leurs propres politiques de confidentialité et de cookies.
- **WhatsApp Business** (bouton « Contacter le cabinet ») ouvre l'application WhatsApp avec un message pré-rempli que vous pouvez modifier ou ne pas envoyer. Si vous l'envoyez, l'échange est soumis aux règles de WhatsApp (Meta) : [politique de confidentialité de WhatsApp](https://www.whatsapp.com/legal/privacy-policy-eea).
- **Laisser un avis** ouvre la page d'avis Google du cabinet. Si vous publiez un avis, il est soumis aux règles de Google : [règles de confidentialité de Google](https://policies.google.com/privacy).
- **E-mail** ouvre votre messagerie habituelle. **Appeler** lance un appel depuis votre téléphone.
- **Vidéos d'étirements** : aucune image ni lecteur YouTube n'est chargé avant que vous touchiez « Lire la vidéo ». Le lecteur utilise alors le mode « confidentialité renforcée » de YouTube (youtube-nocookie.com). À partir de ce moment, YouTube (Google) reçoit des données techniques (adresse IP, appareil) et peut utiliser des traceurs. Les vidéos sont choisies par le cabinet. Voir les [conditions d'utilisation de YouTube](https://www.youtube.com/t/terms) et les [règles de confidentialité de Google](https://policies.google.com/privacy).

Merci de ne pas envoyer d'informations médicales détaillées par message (WhatsApp ou e-mail).

## Hébergement

L'application est hébergée par GitHub Pages (GitHub, Inc.). Selon la documentation de GitHub, l'adresse IP des visiteurs d'un site GitHub Pages est enregistrée et conservée à des fins de sécurité. Voir la [déclaration de confidentialité de GitHub](https://docs.github.com/fr/site-policy/privacy-policies/github-general-privacy-statement).
